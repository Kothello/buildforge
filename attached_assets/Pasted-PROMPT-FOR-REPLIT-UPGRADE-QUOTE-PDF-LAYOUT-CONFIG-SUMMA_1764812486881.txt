2) Parse configuration rather than dumping raw objects

You already fetch a quote with configuration/building details (via storage helper like getLeadQuoteWithDetails). Use configuration JSON to build a summary, not raw .toString().

Assume configuration has arrays like:

- config.windows
- config.doors (or rollUpDoors, personnelDoors)
- config.leanTos

Example parsing:

const config = configuration || {};
const windows = Array.isArray(config.windows) ? config.windows : [];
const doors = Array.isArray(config.doors) ? config.doors : [];
const rollupDoors = Array.isArray(config.rollupDoors) ? config.rollupDoors : [];
const personnelDoors = Array.isArray(config.personnelDoors) ? config.personnelDoors : [];
const leanTos = Array.isArray(config.leanTos) ? config.leanTos : [];

const windowsCount = windows.length;
const rollupCount = rollupDoors.length;
const personnelCount = personnelDoors.length || doors.length;
const leanToCount = leanTos.length;

Guard everything with Array.isArray and optional chaining so the PDF doesn’t crash if the config shape changes.
