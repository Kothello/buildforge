2. New hip geometry: three explicit points

Implement the hip triangle using this approach:

We have two single-slope lean-tos that meet at a corner:

mainLeanTo – along the long wall (front/back).

sideLeanTo – the wraparound child along the perpendicular wall (left/right).

For a given corner (left/right), build a triangle with vertices:

P_high – the top corner of the building at that corner, at the lean-to attach eave height on the tall side.

Use the same X/Z position you already use for the lean-to’s inner roof edge at that corner, and the same Y as that inner roof edge (so the hip lies exactly on the main lean-to roof plane).

P_mainOuter – the outer roof corner of the main lean-to at that same corner.

This is the point you already use for the outer edge of the main lean-to roof at that corner (same X/Z as corner, Y = roof height at that eave + slope).

P_sideOuter – the outer roof corner of the side (wrap) lean-to at that corner.

Use the side lean-to’s outer corner at that corner, again using its real width and roof slope to compute the Y value.

The key is:

Don’t try to be clever about child length or center position.

For the hip triangle, pretend both lean-tos “reach the corner” in roof-space:

just use the corner-adjacent roof corners you already know how to compute (inner and outer corners for each lean-to).

That guarantees all three points lie exactly on the respective roof planes and there is no gap, regardless of the configured length along the wall.

Implementation details:

Re-use the same coordinate system and helpers you’re already using to build the lean-to roof panels (e.g. whatever code currently computes their four roof corners).

Don’t recalc position/length from scratch – instead, call your existing functions or reuse those corner vectors.

Create a THREE.BufferGeometry with exactly 3 vertices (P_high, P_mainOuter, P_sideOuter) and a single face.

Re-use the same material you currently use for roof panels so the hip matches.

UVs can be very simple (e.g. 0/0, 1/0, 0/1) – we just need it textured, not perfect.

Important: This triangle should be rendered for all wraparound single-slope lean-tos, regardless of the wraparound length. Don’t special-case 120′. Just always join the two roofs at the corner with this triangle.
