I want to remove all reliance on page reloads for lead updates and make the CRM update in real time using React Query’s cache.

When I click Save Changes in the building configurator on a lead, I want:

The lead detail page (pricing breakdown, quote total, etc.) to update immediately.

The My Leads list on /sales to show the new price immediately, without me manually refreshing.

No window.location.reload() or full navigation tricks.

Please implement this by wiring React Query’s mutation onSuccess callbacks to update the cache, not by reloading the browser.

1. Lead configurator save → update React Query cache

Open the file that defines the embedded configurator for a lead, which should be:

client/src/configurator/LeadConfiguratorEmbed.tsx

In that file, find the save mutation for updating a lead (the one that calls PATCH /api/leads/:id and is triggered by the "Save Changes" button).

Make sure this mutation uses useMutation from React Query with an onSuccess handler. In that handler:

Get the React Query client:

const queryClient = useQueryClient();


When the mutation succeeds and returns the updated lead (including new totalPrice, buildingSpecs, and configuration), update both:

a) The individual lead query (used by the lead edit/detail page):

queryClient.setQueryData<Lead>(
  ["/api/leads", updatedLead.id],
  updatedLead
);


b) The leads list query (used by /sales My Leads page):

queryClient.setQueryData<Lead[]>(
  ["/api/leads"],
  (old) =>
    old ? old.map((l) => (l.id === updatedLead.id ? updatedLead : l)) : [updatedLead]
);


Remove any code in this file that does a full page reload or navigation just to show updated data, e.g.:

window.location.reload();


or navigate("/sales") used only to force a refresh. The UI should update from the cache instead.

Ensure the “Saved” toast/snackbar still appears, but the component stays on the same page with updated values rendered from the new lead data.
