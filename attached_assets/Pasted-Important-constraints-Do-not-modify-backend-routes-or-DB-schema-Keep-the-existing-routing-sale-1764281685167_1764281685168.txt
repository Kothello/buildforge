/sales/leads/:id shows the full lead detail + configurator and has a Save Changes button.

Problem:

When I change the configuration and click Save Changes, the backend and /sales list are updated.

But if I click View again for that lead (go back to /sales/leads/:id), the edit page still shows the old configuration/price until I hard-refresh the browser.

This means the single-lead data and/or local state on the edit page are stale and not being refreshed from the updated lead.

Desired behavior:

When Save Changes is clicked on /sales/leads/:id and the PATCH succeeds:

The React Query cache for that lead is updated.

The React Query cache for the leads list stays in sync.

If I later click View on that lead again, the /sales/leads/:id page shows the latest configuration and totalPrice without a manual browser refresh.
