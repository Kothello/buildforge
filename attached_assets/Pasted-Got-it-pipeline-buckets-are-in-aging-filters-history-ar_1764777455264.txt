DATA MODEL

In shared/schema.ts create a new table, something like:

export const leadQuoteHistory = sqliteTable("lead_quote_history", {
  id: integer("id").primaryKey({ autoIncrement: true }),
  leadId: integer("lead_id").notNull().references(() => leads.id, { onDelete: "cascade" }),
  totalPrice: integer("total_price").notNull(),
  configuration: text("configuration", { mode: "json" }).notNull(), // or json() depending on existing style
  createdAt: integer("created_at", { mode: "timestamp" }).notNull().default(sql`(strftime('%s','now'))`),
  createdByUserId: integer("created_by_user_id")
    .notNull()
    .references(() => users.id, { onDelete: "set null" }),
});


Adjust to match the existing style in shared/schema.ts (types, timestamps, json vs text, etc.).
