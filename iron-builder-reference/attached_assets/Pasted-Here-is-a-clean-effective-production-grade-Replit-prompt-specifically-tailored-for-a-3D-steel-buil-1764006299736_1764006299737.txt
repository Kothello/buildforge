• A main building
• One or more lean-tos (left, right, rear)
• Doors and windows that snap to walls
• No overlapping of components
• Correct constraints on lean-tos and main building
• Correct local → world → local coordinate transforms
• Guaranteed parent/child hierarchy integrity

Coding Requirements

	•	transform helpers

	•	raycast intersection detection

parent.worldToLocal(point.clone());

const leantoGroup = new THREE.Group();
scene.add(leantoGroup);


	5.	When attaching a door/window to a lean-to wall:
	•	Parent it to the lean-to wall object
	•	Validate overlap only inside that wall’s coordinate system
	6.	Always re-compute bounding boxes after model scaling or resizing.

	4.	Provide corrections when code causes lean-to placement bugs.
