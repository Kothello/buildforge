## What this PR does

This PR fixes navigation/route drift and restores the prefab-era Agent Dashboard while wiring the Pipeline Funnel to real lead data end-to-end (stats, filtering, invalidation, regression tests).

### Commit A — Navigation/Dashboard/IA
SHA: 5eebd31

- Make `/dashboard` deterministic: always renders prefab Agent Dashboard.
- Add `/manager-dashboard`: manager/admin-only view for "Today's Priority Deals".
- Keep `/agent-dashboard` as an alias.
- Repair sidebar IA (Sales / CRM / Admin & Ops) with role-gated items and zero dead links.
- Preserve legacy `/leads?...` deep links with redirect (query + hash preserved).

### Commit B — Funnel stats + stage filtering end-to-end
SHA: 274436e

- Add `GET /api/pipeline/stats?scope=global|my` (auth enforced; REP forced to `my` scope).
- Funnel displays counts from DB, not hardcoded values.
- Normalize stage keys across UI/URL/server to prevent drift:
  - Canonical stage id: `sold_building`
  - Alias: `sold_buildings → sold_building`
- Add server-side stage filtering: `GET /api/leads?stage=<stageId>`
- Add React Query invalidation after lead stage/assignment mutations so funnel updates immediately.
